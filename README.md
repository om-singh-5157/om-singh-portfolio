# Om Singh — Personal Portfolio

A responsive, dark-themed personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- About, experience, projects, skills, certifications, and contact sections
- Downloadable résumé PDF in `assets/`
- Mobile navigation menu
- No framework or build step required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository named `om-singh-5157.github.io` (or any repository name).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Personalise before publishing
- Replace the LinkedIn placeholder URL in `index.html` with your actual profile URL.
- Replace the two GitHub profile links under the project cards with direct repository URLs.
- Check the résumé PDF and all contact details before making the repository public.
- Add a profile photo in `assets/` if you want one; the current design uses an abstract monogram.
